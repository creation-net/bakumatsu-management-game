# 診断テキストの編集場所

画面の見出しと同じ名前のファイルに、表示する文章をまとめています。

- `価値観ともう一つの強み.ts`: 1位の価値観と、2位の強みの説明
- `得意な経営の型.ts`: 1位と2位の組み合わせ別の3段落
- `経営で気を付けたいこと.ts`: 組み合わせ別の注意文と、人物別の予備文章
- `意思決定の特徴.ts`: 1位人物ごとの3項目
- `力を発揮しやすい経営テーマ.ts`: 組み合わせ別の経営テーマ
- `旅を終えたあなたへ.ts`: 完全版の組み合わせ別の手紙と、簡易版の短い手紙

## 組み合わせキー

`1位の人物ID-2位の人物ID` の順です。

- `sakamoto-yoshida`: 1位が坂本 龍馬、2位が吉田 松陰
- `yoshida-sakamoto`: 1位が吉田 松陰、2位が坂本 龍馬

人物IDは次のとおりです。

- `yoshida`: 吉田 松陰（理念型）
- `kusaka`: 久坂 玄瑞（信念型）
- `takasugi`: 高杉 晋作（革新型）
- `kido`: 木戸 孝允（戦略型）
- `sakamoto`: 坂本 龍馬（共創型）
- `omura`: 大村 益次郎（合理型）
- `saigo`: 西郷 隆盛（人望型）
- `okubo`: 大久保 利通（実行型）
- `katsu`: 勝 海舟（調整型）
- `yamagata`: 山縣 有朋（組織型）

人物名、型名、箇条書きの「強み・課題点」は、一つ上の階層にある `diagnosisCharacters.ts` で管理しています。
